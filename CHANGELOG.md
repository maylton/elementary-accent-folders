# Changelog

## 1.0.0

First public release.

- Folder icons follow the elementary OS accent color, including the wallpaper-based *Automatic* accent.
- 10 colors from the official palette, plus an optional `--pastel` style.
- The Files app icon is recolored too.
- Overlay for the Applications Menu, since wingpanel hard-codes the `elementary` icon theme.
- Variants are rebuilt automatically when the system icon theme updates.
- Installs per user with no `sudo` and no dependencies.
- Includes a prebuilt tarball of all variants for people who want a fixed color.
